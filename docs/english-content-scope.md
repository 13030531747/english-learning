# 英语主练习题库范围与审校说明

英语主练习题库的数量是当前应用内置库存数，不代表历年真题频率、考试权重或完整考纲覆盖。高考选择题、语法填空和完形填空仍由独立数据模块管理。

本轮扩充重点：

- 动词后接动名词、不定式、原形、宾语加补语的句法位置；
- 介词由动词、形容词和名词支配时的宾语位置；
- 可分与不可分短语动词，以及代词宾语的位置；
- 感官动词、使役动词、被动结构和分词复合结构；
- 从句边界、倒装、虚拟语气、平行结构、主谓一致；
- 易混词的词性槽位、可数性和语义限制。

每道新增题均设置完整语境、一个目标答案和三个干扰项。结构测试只能检查 ID、字段和选项映射；英文表达的自然度、答案唯一性、翻译和解释仍需逐题人工复核。题库不标注未经核验的真题出处，也不据此宣称考频。

已知边界：题库仍不是完整语法课程，个别结构可能存在其他语法上成立但语义不同的表达。后续发现多解题时，应优先补充语境或替换干扰项，而不是依赖题目标签强行判定。
